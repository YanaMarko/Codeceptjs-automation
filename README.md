# Автоматизация тестирования на CodeceptJS 🚀

Добро пожаловать! В этом репозитории собраны мои учебные проекты, практические работы и автотесты, написанные в процессе изучения фреймворка **CodeceptJS**.

## 🛠️ Используемый стек технологий
* **Язык:** JavaScript (Node.js)
* **Фреймворк:** CodeceptJS
* **Движок автоматизации (Helper):** Playwright
* **Браузер для тестов:** Chromium

## 📂 Структура репозитория
* `google_test.js` — первый базовый приемочный тест (проверка доступности веб-страниц).
* *(Сюда я буду добавлять новые тестовые сценарии, Page Objects и кастомные шаги по мере обучения).*

## 🚀 Как запустить тесты локально

1. Клонировать репозиторий или открыть папку с проектом.
2. Установить все необходимые зависимости (библиотеки) из файла `package.json`:
   ```bash
   npm install
   ```
3. Скачать изолированные браузерные движки Playwright:
   ```bash
   npx playwright install
   ```
4. Запустить выполнение автотестов с отображением каждого шага в консоли:
   ```bash
   npx codeceptjs run --steps
   ```
