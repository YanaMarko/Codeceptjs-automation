# Автоматизация тестирования на CodeceptJS + Playwright 🚀

Учебный проект по автоматизации тестирования веб-приложений с использованием современного стека технологий. Проект создан в процессе обучения для демонстрации базовых навыков написания автотестов и настройки отчетности.

---

## 🛠 Стек технологий

* **Фреймворк:** [CodeceptJS](https://codecept.io) — высокоуровневый фреймворк для сквозного (E2E) тестирования с простым и понятным синтаксисом.
* **Движок автоматизации (Helper):** [Playwright](https://playwright.dev) — быстрый и надежный инструмент для управления браузерами.
* **Язык программирования:** JavaScript (Node.js).
* **Отчетность:** [Allure Report](https://allurereport.org) — интерактивные графики и подробные шаги выполнения тестов.

---

## 💻 Требования для локального запуска

Для запуска тестов на твоем компьютере должны быть установлены:
1. **Node.js** (рекомендуется версия LTS).
2. **Java (JRE/JDK)** (необходима для корректной сборки и работы Allure-отчетов).

---

## 📦 Быстрый старт и установка

1. **Клонируй репозиторий себе на компьютер:**
   ```bash
   git clone https://github.com
   ```
2. **Перейди в папку проекта:**
   ```bash
   cd Codeceptjs-automation
   ```
3. **Установи все зависимости проекта начисто:**
   ```bash
   npm install --legacy-peer-deps
   ```

---

## 🏃‍♂️ Как запускать тесты и отчеты

### 1. Запуск автотестов
Чтобы запустить тесты в реальном браузере Chrome с выводом каждого шага в консоль, выполни:
```bash
npx codeceptjs run --steps
```

### 2. Просмотр красивых Allure-отчетов 📊
Чтобы превратить результаты выполнения тестов в интерактивную веб-страницу с круговыми диаграммами и хронологией шагов, выполни:
```bash
npx allure-commandline serve output/allure-results
```
*Команда автоматически соберет сырые логи из папки `output`, поднимет локальный сервер и сама откроет вкладку с готовым отчетом в твоем браузере.*

## 📂 Структура проекта

* `google_test.js` — базовый тестовый сценарий для проверки доступности веб-страниц.
* `codecept.conf.js` — главный конфигурационный файл проекта (настройки Playwright, выбор браузера и подключение Allure-плагина).
* `package.json` — описание проекта, список используемых библиотек и их версий.
* `output/` — папка, куда сохраняются логи выполнения и результаты Allure.
